# osmnorhn.github.io

Personal website of Osman Orhan, served by GitHub Pages at https://osmnorhn.github.io.

A single static `index.html` styled like a backend developer's terminal: no build step and no dependencies apart from the JetBrains Mono web font.
To preview locally, open `index.html` in a browser or run `python3 -m http.server`.
